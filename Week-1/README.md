# Week 1 – First LLM API Call

## Aim
To understand how to connect a Python application to a Large Language Model (LLM) using the Google Gemini API and generate a response from a given prompt.

## Introduction
In this experiment, I created a simple Python application that communicates with Google's Gemini model. The application sends a text prompt to the model and displays the generated response.

The experiment also demonstrates how to securely manage API credentials using environment variables instead of directly writing API keys in the source code.

## Technologies Used

| Technology | Purpose |
|---|---|
| Python | Main programming language |
| Google Gemini API | Generates responses to prompts |
| Google GenAI SDK | Connects the Python application to Gemini |
| python-dotenv | Loads environment variables from the `.env` file |

## Files Included

- `main.py` – Contains the Python code to connect to Gemini and generate a response.
- `requirements.txt` – Lists the required Python packages.
- `.env` – Stores the Gemini API key locally. This file is not uploaded to GitHub.
- `.gitignore` – Prevents sensitive and unnecessary files from being tracked by Git.

## Implementation

The implementation follows these steps:

1. Import the required Python libraries.
2. Load environment variables using `load_dotenv()`.
3. Read the Gemini API key using `os.getenv()`.
4. Check whether the API key is available.
5. Initialize the Gemini client using the Google GenAI SDK.
6. Send a prompt to the `gemini-3.5-flash-lite` model.
7. Display the generated response using `print()`.

## Execution

Install the required packages:

pip install -r requirements.txt

Add the Gemini API key to the local .env file:

GEMINI_API_KEY=your_api_key_here

Run the Python program:

python main.py

## Expected Output

The program displays a heading:

LLM Response:

Below this heading, it displays the Gemini model's response explaining Artificial Intelligence in simple words.

Note: The actual response is generated by the API and may vary between executions.
