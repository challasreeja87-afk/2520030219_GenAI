# Week 6 – Golden Set Evaluation and Baseline Testing

## Aim

To evaluate the responses generated by a Large Language Model (LLM) using a predefined Golden Question Set and establish a baseline performance report.

## Project Description

This experiment uses Ollama with the Llama 3.2 model to generate answers for a collection of 30 predefined questions.

The generated answers are compared against expected keywords. A keyword coverage score is calculated for each response, and the evaluation results are stored in a CSV file.

The baseline report helps identify how well the model responds to the given questions and which responses require further review.

## Technologies Used

| Technology | Purpose |
|---|---|
| Python | Core implementation |
| Ollama | Running the local LLM |
| Llama 3.2 | Generating answers |
| Requests | Communicating with the Ollama API |
| JSON | Storing the Golden Question Set |
| CSV | Saving evaluation results |

## Implementation

### 1. Configuration
- Configures the local Ollama API endpoint.
- Selects the Llama 3.2 model.
- Defines the input JSON and output CSV filenames.

### 2. Golden Question Set
- Loads 30 predefined questions from `golden_set.json`.
- Each question contains an ID, question, expected answer, keywords and source reference.

### 3. LLM Response Generation
- Sends each question to the Ollama API.
- Generates responses using Llama 3.2.
- Uses temperature 0 for more consistent generation.

### 4. Keyword-Based Scoring
- Converts the generated answer to lowercase.
- Checks which expected keywords appear in the response.
- Identifies matched and missing keywords.
- Calculates the keyword coverage percentage.

**Scoring formula:**

```text
Score = (Matched Keywords / Total Keywords) × 100
```

### 5. Evaluation Status

| Status | Condition |
|---|---|
| PASS | Score is 60% or higher |
| REVIEW | Score is below 60% |
| ERROR | An exception occurs during the request |

### 6. Baseline Results
The evaluation results are saved in `baseline_results.csv`.

The CSV contains:
- Question ID and question
- Expected answer
- Generated LLM answer
- Matched keywords
- Missing keywords
- Score and evaluation status
- Source reference
- Model name and release version

### 7. Baseline Summary
After processing all questions, the program displays:
- Total questions
- Successful responses
- Passed questions
- Questions requiring review
- Failed requests
- Average keyword coverage
- Evaluation date

## Execution Steps

**Step 1: Install dependencies**

```powershell
pip install -r requirements.txt
```

**Step 2: Start Ollama**

Make sure Ollama is running and the Llama 3.2 model is available.

```powershell
ollama run llama3.2
```

**Step 3: Execute the program**

Open another terminal in the Week-6 folder and run:

```powershell
python main.py
```

**Step 4: View the results**

After successful execution, the generated baseline report is available in:

```text
baseline_results.csv
```

## Output

The program successfully:
- Loaded the Golden Question Set.
- Generated LLM responses using Ollama.
- Evaluated responses using keyword matching.
- Calculated individual keyword coverage scores.
- Classified responses into PASS, REVIEW and ERROR.
- Generated `baseline_results.csv` containing 30 evaluation records.
- Displayed the baseline evaluation summary.

## Conclusion

This experiment established a baseline evaluation system for an LLM using a predefined Golden Question Set. It demonstrated how automated response generation, keyword-based scoring and CSV reporting can be combined to evaluate model outputs.

The baseline results can be used as a reference for comparing future model versions or improvements to the evaluation system.
