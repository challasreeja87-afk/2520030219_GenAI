# Week 7 – Next-Token Probability Analysis

## Aim

To inspect logits and top-K next-token candidates generated by a small pretrained open-source language model using Hugging Face Transformers.

## Project Description

This experiment uses the DistilGPT-2 pretrained language model to analyze how a language model predicts its next token.

A sample input prompt is provided to the model. The model generates logits for the next token, which are converted into probabilities using the Softmax function.

The program then identifies and displays the top 5 most probable next-token candidates along with their token IDs and probability percentages.

## Implementation

### 1. Load the Pretrained Model
- Uses the DistilGPT-2 pretrained model.
- Loads the model and tokenizer using Hugging Face Transformers.
- Sets the model to evaluation mode.

### 2. Define Input Prompt
The input prompt used is:

```text
The capital of France is
```

The tokenizer converts the prompt into input token IDs.

### 3. Generate Logits
- Passes the tokenized input to the model.
- Uses `torch.no_grad()` to avoid gradient calculations.
- Extracts the logits for the final input position.
- Displays the shape of the logits tensor.

### 4. Convert Logits into Probabilities

Uses the Softmax function:

```python
probabilities = torch.softmax(logits, dim=-1)
```

This converts the raw logits into probability values.

### 5. Extract Top-K Candidates
- Uses `torch.topk()` to select the five highest-probability tokens.
- Displays each candidate's token text, token ID and probability.
- Uses the tokenizer to decode token IDs into readable text.

### 6. Display the Most Probable Token

The program identifies the candidate with the highest probability and displays it as the most probable next token.
